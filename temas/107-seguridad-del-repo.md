# SECURITY.md y protección contra secretos

- **SECURITY.md**: explica cómo reportar vulnerabilidades en privado. GitHub lo muestra en la pestaña *Security*.
- **Private vulnerability reporting**: permite que te reporten fallas sin abrir un issue público.
- **Secret scanning y push protection**: GitHub detecta tokens y llaves, y bloquea el `push` antes de que el secreto llegue al repo.

Todo se activa en *Settings → Code security*. En repos públicos es gratis.
