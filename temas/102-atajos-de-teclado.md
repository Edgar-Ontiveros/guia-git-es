# Atajos de teclado en GitHub

| Tecla | Acción |
|---|---|
| `?` | ver todos los atajos |
| `/` | ir a la búsqueda |
| `t` | buscar un archivo en el repo |
| `.` | abrir el repo en el editor web (github.dev) |
| `y` | enlace permanente al commit actual |
| `b` | ver blame del archivo |
| `g` `c` / `g` `i` / `g` `p` | ir a código / issues / pull requests |

`.` es muy útil para editar varios archivos sin clonar.
