# Búsqueda avanzada en GitHub

```
is:pr is:open review-requested:@me            # PRs que esperan tu revisión
is:issue is:open assignee:@me
repo:usuario/repo label:bug
language:python stars:>500 topic:fastapi
path:*.yml actions/checkout                   # búsqueda de código
org:mi-empresa "SAP HANA"
```

Guarda las búsquedas que usas seguido como marcadores o en la barra de búsqueda de GitHub.
