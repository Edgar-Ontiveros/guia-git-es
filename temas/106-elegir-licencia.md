# Elegir una licencia

Sin licencia, tu código es "todos los derechos reservados": otros pueden verlo, pero no usarlo legalmente.

- **MIT**: muy permisiva, solo pide conservar el aviso de copyright.
- **Apache-2.0**: permisiva y además cubre patentes.
- **GPL-3.0**: quien distribuya versiones modificadas debe publicar su código con la misma licencia.

En GitHub: *Add file → Create new file*, escribe `LICENSE` y usa **Choose a license template**. Guía: <https://choosealicense.com>.
