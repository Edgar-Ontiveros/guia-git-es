# Ver el diff mientras escribes el commit

```bash
git commit -v
```

Abre el editor con el diff completo debajo del mensaje (esa parte no se guarda). Ayuda a escribir un mensaje que describa lo que realmente cambió.

Déjalo como predeterminado:

```bash
git config --global commit.verbose true
```
