# Markdown de GitHub: lo más útil

```markdown
- [ ] tarea pendiente
- [x] tarea hecha

| Columna | Otra |
|---|:---:|
| texto | centrado |

> [!NOTE]
> Información útil.

> [!WARNING]
> Cuidado con esto.

<details>
<summary>Ver detalles</summary>

Contenido oculto.
</details>
```

También: `#123` enlaza issues, `@usuario` menciona, `:rocket:` pone emoji y `[^1]` crea notas al pie.
