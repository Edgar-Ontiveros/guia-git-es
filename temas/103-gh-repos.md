# Repositorios con GitHub CLI

```bash
gh repo create mi-app --private --clone          # crea y clona
gh repo create --source . --public --push        # publica una carpeta local existente
gh repo clone usuario/repo
gh repo fork org/proyecto --clone                # fork y clon con upstream configurado
gh repo view --web
gh repo edit --description "Nueva descripción" --add-topic python
```
