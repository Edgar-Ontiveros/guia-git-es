# Escribir buenos mensajes de commit

Un buen mensaje explica **qué** cambia y **por qué**, no cómo (eso ya lo dice el diff).

```
Corrige el cálculo del IVA en notas de crédito

Las notas de crédito restaban el IVA dos veces cuando el
documento original tenía descuento global.
```

Convenciones útiles:

- Primera línea de 50–72 caracteres, en imperativo ("Agrega", "Corrige").
- Línea en blanco y luego el detalle.
- Si sigues Conventional Commits: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`.
