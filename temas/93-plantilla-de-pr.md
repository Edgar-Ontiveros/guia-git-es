# Plantilla de pull request

Crea `.github/pull_request_template.md`:

```markdown
## ¿Qué cambia?

## ¿Por qué?

## ¿Cómo se probó?

- [ ] Pruebas automáticas
- [ ] Prueba manual

Closes #
```

Cada PR nuevo empieza con este texto, y las revisiones son más rápidas porque el contexto siempre está.
