# Cerrar issues desde un commit o PR

Si el mensaje del commit o la descripción del PR incluye una palabra clave y el número del issue, GitHub lo cierra al integrar a la rama principal:

```
Corrige el redondeo de totales

Closes #12
```

Palabras válidas: `close`, `closes`, `closed`, `fix`, `fixes`, `fixed`, `resolve`, `resolves`, `resolved`.

Para otro repositorio: `Fixes usuario/repo#12`.
