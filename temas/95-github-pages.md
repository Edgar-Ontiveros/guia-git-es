# Publicar un sitio con GitHub Pages

1. *Settings → Pages*.
2. Fuente: **Deploy from a branch** (`main` y carpeta `/` o `/docs`) o **GitHub Actions** si necesitas compilar el sitio.
3. Tu sitio queda en `https://usuario.github.io/repo/`.

Un repo llamado exactamente `usuario.github.io` se publica en la raíz `https://usuario.github.io/`.

Para usar tu propio dominio, configúralo en la misma página y agrega el registro DNS que te indica.
