# Enlaces permanentes a líneas de código

En la vista de un archivo en GitHub:

- Haz clic en un número de línea y con **Shift** en otro para seleccionar un rango (`#L10-L20`).
- Presiona **y** para cambiar la URL de la rama al hash del commit.

Así el enlace sigue apuntando al mismo código aunque el archivo cambie después. Si pegas ese enlace en un issue o PR, GitHub muestra el fragmento de código.
