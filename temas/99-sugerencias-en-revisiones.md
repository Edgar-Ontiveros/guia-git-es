# Sugerir cambios en una revisión de PR

Al comentar una línea de un PR, usa un bloque `suggestion`:

````markdown
```suggestion
total = subtotal * (1 + tasa_iva)
```
````

El autor puede aplicarlo con **Commit suggestion**, o juntar varios con **Add suggestion to batch** y hacer un solo commit. Es más rápido que describir el cambio con palabras.
